# Protein Quantifications aggregated from Peptide Quantifications

## Using DirectLFQ

See GitHub repository [DirectLFQ](https://github.com/MannLabs/directlfq) and
[protein_quant.py](protein_quant.py) script for details. In short:

- bring the peptide quantifications into a suitable format
- run DirectLFQ to aggregate peptide to protein quantifications with default parameters
- filter and reshape the results
